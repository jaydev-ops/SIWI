## SIWI Global Ventures Design Execution

Conduct a comprehensive responsive design review across Mobile (<640px) and Tablet (640–1023px) viewports for SIWI Global Ventures.

Ensure that the asymmetric desktop layouts collapse gracefully into clean vertical sequences while preserving the 8px spacing scale, legible typography, and touch ergonomics.

---

## 3. SELF-CONTAINED TASK BRIEF (FOR DIRECT PASTE)
> **Target Viewports:** Mobile (390px / 480px) and Tablet (768px / 1024px)  
> **Key Areas to Audit:**  
> - **Mobile Navigation:** Clean drawer menu with touch-friendly links (>= 44px), phone/email shortcuts, and theme switch.  
> - **Hero Stacking:** Headline first, supporting text, immediate primary CTA, followed by cropped macro ingredient visual. Zero text overlap over images.  
> - **Product Grid Adaptation:** 2-column product catalogue transitions to a clean single-column or 2-column compact format.  
> - **Form Ergonomics:** Form inputs stack vertically with generous touch padding and visible labels.  
> - **Zero Horizontal Overflow:** Container padding of 20px–24px on mobile; zero sideways scrolling.

---

## 4. CONSTRAINTS & NEGATIVE RULES
- Do NOT shrink desktop layouts into unreadable miniatures.
- Interactive targets must NEVER be smaller than 44px × 44px.
- Navigation links must never crowd or wrap awkwardly in the header.

---

## 5. EXPECTED DELIVERABLES
1. High-fidelity mobile layout of Homepage (390px viewport).
2. Mobile layout of Product Detail Page and Trade Enquiries Form.
3. Mobile Navigation Drawer open-state wireframe.
