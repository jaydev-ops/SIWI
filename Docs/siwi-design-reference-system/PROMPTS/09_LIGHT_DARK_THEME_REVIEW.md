# STITCH TASK PROMPT 09 — LIGHT & DARK THEME REVIEW
## SIWI Global Ventures Design Execution

---

## 1. TASK ASSIGNMENT
Conduct a side-by-side design review and quality audit of the SIWI Global Ventures website in both Dark Mode and Light Mode.

The objective is to guarantee theme parity, ensuring both modes feel intentional, luxurious, and WCAG AA accessible, without either mode looking like a crude color inversion of the other.

---

## 2. REQUIRED REFERENCE DOCUMENTS
Provide the following documents to Stitch:
- `LEVEL_02_VISUAL_DESIGN_SYSTEM.md` (Section 4 Colour System)
- `LEVEL_06_RESPONSIVENESS_AND_QUALITY.md` (Section 2 Accessibility & Section 6 Checklist)

---

## 3. SELF-CONTAINED TASK BRIEF (FOR DIRECT PASTE)
> **Theme Specifications:**  
> - **Dark Mode (Core Identity):** Base background: deep near-black (`#111318`). Surfaces: charcoal (`#191C21`). Text: warm ivory (`#F5F2EB`). Accents: metallic gold (`#C69A45`). Borders: `rgba(245, 242, 235, 0.12)`.  
> - **Light Mode (Editorial Journal):** Base background: warm ivory (`#FAF8F5` / `#F5F2EB`). Elevated surfaces: pure white (`#FFFFFF`) or stone (`#F2EFEB`). Text: ink (`#111318`). Accents: burnished gold (`#B88B35`). Borders: `rgba(17, 19, 24, 0.10)`.  
> - **Audit Requirements:** Test contrast across body text (minimum 4.5:1), large text (minimum 3.0:1), and UI boundaries. Ensure logos, compass linework, and borders adapt naturally.

---

## 4. CONSTRAINTS & NEGATIVE RULES
- Light mode must NOT be a sterile, blinding pure white box.
- Gold must never become illegible on light ivory surfaces (use burnished tone `#B88B35`).
- Dark mode must NOT simply invert images or photographs.

---

4. Contrast ratio verification report for key text and UI tokens.
