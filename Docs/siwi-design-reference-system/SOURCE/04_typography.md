# 4. TYPOGRAPHY — APPLE-INSPIRED, NOT GENERIC AI TYPOGRAPHY

Typography is one of the most important aspects of this website.

Use the restrained, precise typographic approach associated with Apple's product and corporate interfaces.

The goal is not to copy Apple's website. The goal is to apply its discipline to a serious international trade brand.

## Primary sans-serif typeface

Prioritise the following font stack:

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "SF Pro Display",
  "SF Pro Text",
  "Helvetica Neue",
  Arial,
  sans-serif;
```

Use appropriate system-font fallbacks on Windows, Android, and other platforms.

Do not assume SF Pro is installed on every visitor's device. If a licensed font file is supplied, use it appropriately; otherwise, allow the system font stack to work naturally.

## Serif typeface

Use a restrained editorial serif for the SIWI wordmark, selected major headings, and occasional brand statements.

Preferred options:
- Cormorant Garamond
- Libre Baskerville
- Georgia as a system fallback

Use the serif sparingly.

The website should not become an old-fashioned luxury hotel website.

The combination should feel contemporary, commercial, and globally relevant.

## Typographic hierarchy

Establish a consistent typographic scale.

| Element | Desktop size | Weight | Treatment |
|---|---|---|---|
| Main hero headline | 64–88px | Regular to medium | Tight, deliberate line breaks |
| Page headline | 52–72px | Regular | Editorial, spacious |
| Major section heading | 36–48px | Regular | Clear and confident |
| Secondary heading | 24–32px | Medium | Compact and readable |
| Product name | 20–26px | Medium | Clean, direct |
| Body text | 16–18px | Regular | Comfortable line height |
| Supporting description | 14–16px | Regular | Muted but legible |
| Eyebrow label | 11–13px | Medium | Restrained uppercase |
| Navigation | 13–15px | Medium | Consistent spacing |
| Metadata | 12–14px | Regular | High clarity |

These are starting points, not rigid rules. Adjust them for actual content, screen size, and the visual composition.

## Typography rules

- Prefer regular and medium weights over heavy bold.
- Use bold only when hierarchy genuinely requires it.
- Avoid using oversized bold text for every heading.
- Avoid excessive letter spacing in body text.
- Use uppercase primarily for short labels and metadata.
- Keep body text line length around 55–75 characters where practical.
- Set body line-height around 1.5–1.75.
- Set display-heading line-height around 0.98–1.12, depending on the typeface.
- Use natural sentence case for most headings.
- Use typographic contrast instead of coloured boxes to establish hierarchy.
- Keep headings short and intentional.

## Hero typography

The homepage hero must have one unmistakable primary headline.

Do not use three competing headlines, multiple oversized statistics, or several unrelated messages in the same visual area.

The hero should communicate the business in seconds.

**Suggested headline:**
> Indian products.
> Global possibilities.

**Supporting copy:**
> "SIWI Global Ventures connects quality Indian products with international markets through dependable trade partnerships and a focus on quality."

**Primary CTA:** Explore Our Products

**Secondary CTA:** Discuss Your Requirements

Use an editorial serif for a small, carefully selected phrase only if it improves the composition.

The headline should remain legible, confident, and relatively short.
