# 23. NAVIGATION AND INFORMATION ARCHITECTURE

The navigation must remain clear across the entire website.

## Desktop navigation

**Left:** SIWI Global Ventures logo.

**Centre or right:**
- Home.
- About.
- Products.
- Trade Enquiries.
- Contact.

**Far right:**
- Theme toggle.
- Enquiry CTA.

Do not overcrowd the navigation with every product category. Use a dropdown under Products.

## Products dropdown

Group the products under clear headings.

**Dehydrated Vegetables:**
- Onion Powder.
- Garlic Powder.
- Garlic Granules.
- Dehydrated Fried Onions.
- Birista.
- Onion Kibbles.
- Other Value-Added Products.

**Other Categories:**
- Tiles.
- Other Products.

## Mobile navigation

Use a clean mobile menu.

Requirements:
- Accessible menu button.
- Visible close button.
- Logical focus order.
- Keyboard support.
- Proper screen-reader labels.
- Appropriate touch-target sizes.
- No horizontal overflow.
- No accidental opening or closing from unrelated interactions.

Do not use an oversized full-screen menu if a simpler solution works better.

## Breadcrumbs

Use breadcrumbs on product detail pages.

**Example:**
Home → Products → Dehydrated Vegetables → Onion Powder

Breadcrumbs should remain subtle and readable.
