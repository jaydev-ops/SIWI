# 30. ACCESSIBILITY

Treat accessibility as part of the design, not as an afterthought.

## Implement

- Semantic HTML.
- Logical heading hierarchy.
- Keyboard-accessible navigation.
- Visible focus indicators.
- Sufficient colour contrast.
- Descriptive image alt text.
- Accessible form labels.
- Clear validation errors.
- Screen-reader-friendly status messages.
- Reduced-motion support.
- Appropriate button and link semantics.

## Rules

- Do not use colour alone to communicate important information.
- Do not remove focus outlines without replacing them with a clear alternative.
- Ensure gold text remains readable against the selected background.
