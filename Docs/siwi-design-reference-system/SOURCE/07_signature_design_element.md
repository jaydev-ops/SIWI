# 7. THE SIGNATURE DESIGN ELEMENT — THE GLOBAL COMPASS

Create one recognisable design motif based on the existing SIWI globe-and-compass logo.

This should become the website's signature visual language.

The compass represents direction, international movement, navigation, and the connection between markets.

Use this idea to create visual consistency without repeating the full logo everywhere.

## Possible applications

**Homepage hero**
A large, refined globe-and-directional-line composition placed beside or behind the headline.

**Product pages**
Small directional markers identifying product categories or navigation between related products.

**About page**
A thin-line globe and a restrained graphic illustrating the company's role in connecting Indian products with global markets.

**Contact page**
A directional line or compass-inspired layout that leads the visitor towards the enquiry form.

**Footer**
A small, understated compass mark accompanying the SIWI wordmark.

## Visual treatment

- Use fine ivory or gold strokes.
- Keep the line work precise.
- Use restrained geometry.
- Prefer vector graphics or a carefully created SVG.
- Preserve sufficient negative space.
- Use asymmetry where appropriate.
- Avoid decorative movement that interferes with readability.

Do not use a spinning globe on every page.

Do not use stock illustrations of aeroplanes, cargo ships, shipping containers, and dotted world maps as generic international-trade decoration.

The signature motif should feel like it belongs specifically to SIWI Global Ventures.
