# 31. SEO AND PERFORMANCE

Build the website with search visibility, performance, and maintainability in mind.

## SEO

Provide:
- Unique page titles.
- Unique meta descriptions.
- Canonical URLs where appropriate.
- Semantic page structure.
- Descriptive image alt text.
- Open Graph metadata.
- Appropriate heading hierarchy.
- Internal links between relevant products.
- A sitemap.
- A robots.txt file.

Use structured data only where it accurately represents the company and the information available.

Do not add fabricated ratings, reviews, certifications, or business attributes.

## Performance

- Optimise images.
- Use responsive image sizes.
- Lazy-load below-the-fold images.
- Avoid unnecessary animation libraries.
- Minimise layout shifts.
- Avoid oversized background videos.
- Load fonts responsibly.
- Keep the initial page load lightweight.
- Avoid unnecessary third-party scripts.

## Suggested targets

Aim for strong Core Web Vitals and a Lighthouse performance score of 90 or higher where practical.

Treat this as a performance objective rather than a guaranteed score.
