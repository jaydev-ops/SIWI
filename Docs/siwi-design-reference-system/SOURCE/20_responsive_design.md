# 29. RESPONSIVE DESIGN

The website must be designed for real use on desktop, tablet, and mobile.

Do not design only for a 1440px desktop viewport and then scale everything down.

## Desktop

- Use a clear grid.
- Preserve generous margins.
- Allow asymmetric compositions.
- Use high-quality product imagery.
- Keep navigation compact.
- Prevent excessive line lengths.

## Tablet

- Reduce horizontal whitespace intelligently.
- Simplify multi-column layouts.
- Preserve typographic hierarchy.
- Ensure product imagery remains prominent.

## Mobile

- Use a single-column reading flow where appropriate.
- Keep headings readable.
- Prevent clipped text.
- Make navigation easy to use.
- Use comfortable touch targets.
- Keep forms easy to complete.
- Avoid horizontal scrolling.
- Ensure images do not overwhelm the content.
- Avoid placing important text inside images.

## Minimum requirements

- No horizontal overflow at common viewport widths.
- No overlapping navigation elements.
- No inaccessible dropdowns.
- No clipped buttons.
- No text that becomes unreadably small.
- No forms requiring awkward horizontal scrolling.

## Test viewports

Test at approximately:
- 360px.
- 390px.
- 768px.
- 1024px.
- 1440px.
- 1920px.

Use fluid sizing where appropriate rather than relying exclusively on fixed pixel values.
