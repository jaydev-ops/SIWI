# 10. USE FEWER CARDS

The default layout must not be a collection of rounded rectangles.

Cards are permitted only when they genuinely improve comprehension or interaction.

## Avoid

- Three identical cards below every heading.
- Rounded rectangles around ordinary paragraphs.
- A separate card for every statistic.
- Floating cards with shadows.
- Nested cards.
- Excessive pill-shaped labels.
- Dashboard-style layouts on corporate pages.
- Repeated icon-heading-description combinations.

## Prefer

- Editorial columns.
- Asymmetric image layouts.
- Fine horizontal rules.
- Large typographic headings.
- Full-width image sections.
- Simple lists.
- Open layouts.
- Carefully aligned text and imagery.
- Numbered steps where sequencing matters.
- Subtle changes in background colour.

## Where cards are appropriate

Cards can be used for:
- Interactive product selection, if it genuinely improves usability.
- Enquiry form groupings.
- Structured product specifications.
- Mobile-specific layouts.
- Compact interactive elements.

Use minimal corner radii, subtle borders, and restrained shadows.

Do not apply a large border radius to every component.

The website should rely on composition, not containers, to create structure.
